## Featured Project

### Fake Job Posting Detection

Senior Project II web application that classifies job postings as real or potentially fraudulent using their titles and descriptions.

My contributions included:
- Preparing text data and building TF-IDF and additional binary features.
- Comparing Logistic Regression, Random Forest, and SVM models using precision, recall, F1-score, and ROC-AUC.
- Working with an imbalanced dataset and using SMOTE in the model pipeline.
- Contributing to the FastAPI application, project documentation, and visualizations.
